# HImpact Project Index

> **The Single Source of Truth for the HImpact Digital Event Automation Platform**

---

## Overview

The **Project Index** contains the complete business, product, architecture, design, and technical documentation for the HImpact platform.

It serves as the authoritative reference for all project decisions and implementation. Every developer, designer, AI assistant, tester, and stakeholder should reference these documents before making changes to the system.

The Project Index follows a documentation-first approach to minimize ambiguity, reduce implementation rework, and maintain consistency across the platform.

# Project Objectives

The HImpact platform aims to:

- Simplify event management through automation.
- Deliver a premium mobile-first guest experience.
- Preserve event memories securely.
- Minimize operational costs using cloud-native and free-tier technologies where practical.
- Build a scalable architecture capable of supporting multiple event types beyond weddings.
