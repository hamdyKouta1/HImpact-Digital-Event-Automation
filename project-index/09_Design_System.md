# Purpose

This document defines the visual language and reusable design components for the HImpact Digital Event Automation Platform.

The design system ensures visual consistency across all applications while enabling rapid development and future scalability.

# Accessibility

The design system shall:

- Meet WCAG AA recommendations.
- Maintain accessible color contrast.
- Support keyboard navigation.
- Display visible focus indicators.
- Avoid color-only communication.
